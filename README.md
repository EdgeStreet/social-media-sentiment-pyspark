# Social Media Sentiment Dataset Basic Analysis

## Project Description
This is a Big Data practical project using PySpark.  
The project performs basic analysis on a Twitter sentiment dataset.

## Dataset
Dataset: Twitter Dataset from Kaggle  
CSV filename used locally: twitter_dataset.csv

## Tool Used
PySpark

## Tasks Performed
1. Load dataset
2. Count posts per category
3. Filter positive and negative posts
4. Find most frequent keywords
5. Display summary output

## Files
- main.py: Main PySpark code file
- twitter_dataset.csv: Dataset file used locally

## How to Run
Place `main.py` and `twitter_dataset.csv` in the same folder.

Run the project using:

```bash
python main.py
